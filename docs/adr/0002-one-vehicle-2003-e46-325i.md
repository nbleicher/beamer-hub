# One Vehicle: 2003 E46 325i `WBAET374X3NJ32467`

The app is bound to this VIN, not to “a BMW.” NHTSA decodes it as a 2003 325i sedan (model code 0345, trim SA, 4-door, 6-cylinder gasoline, 184 hp, Pretoria). A 2014 F30 and this E46 do not share a parts catalog, 3D model, or service system.

Adding a second vehicle later is a new context, not a setting.
