# v1 selects a Region with a Query, not a 3D model

The Owner types “back left window” or “interior trunk left lightbulb” and lands on a Region (and any Check Sequence on it). The 3D Viewer is deferred until MediaPool, the dealer, or a purchased GLB exists.

Orbit-3D (ADR-0006) is still the later picker. A Query does not create a new Region and does not resolve an ETK part. “Lightbulb” is an alias for trunk interior, not a catalog SKU.
