# A Query miss shows closest hits; add is gated

On a miss, show the closest Regions and the closest Catalog Parts. The Owner may add an **alias** to an existing Region, or a **Part** only by pasting a BMW part number (from ETK / the dealer / RealOEM they looked up). They may add a coarse Region rarely. They may not add a free-text “part” that has no number.

A complete Catalog is VIN-filtered ETK for `J32467`, not a longer Region list and not an LLM. AI does not invent part numbers.
