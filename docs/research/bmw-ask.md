# What to ask BMW (corporate), not the dealer

Three different doors. One sentence each. Do not send the 3D question to Customer Relations — they will try to book a service appointment.

## 1. The 3D file — BMW Group MediaPool

BMW’s official 3D cars live in **MediaPool**. Their price list says 3D models have a one-time usage fee **invoiced inside BMW**; outside agencies are not billed directly. That means a private owner does not check out an E46 `.glb` without a BMW department sponsoring the request.

Email: [mediapool@bmw.de](mailto:mediapool@bmw.de) (listed on [MediaPool contacts](https://mediapool.bmwgroup.com/download/edown/common/info?actEvent=contact)). Portal: [mediapool.bmwgroup.com](https://mediapool.bmwgroup.com/).

> I own a 2003 325i sedan (VIN `WBAET374X3NJ32467`). May I license an **E46 sedan 3D model** (GLB/glTF/FBX, separate doors/hood/trunk) from MediaPool for a **private, non-commercial** browser tool that only I use? If yes, what is the process and fee? If MediaPool only supplies current models or only BMW-sponsored agencies, please say so.

Expected answer: no, or “have a BMW project number.” That is still the right ask. A yes is the only official mesh.

## 2. This VIN — BMW of North America Customer Relations

Not 3D. Campaigns and owner records.

Call **1-800-831-1117** or [bmwusa.com/contact-us](https://www.bmwusa.com/contact-us.html). Recalls also: [my.bmwusa.com/safety-and-emission-recalls](https://my.bmwusa.com/safety-and-emission-recalls/manage) and hotline **1-800-525-7417**.

> Please pull **open safety and emissions campaigns** and any **factory build / option list** you can release to the titled owner for VIN `WBAET374X3NJ32467` (2003 325i). I need campaign numbers, not a marketing brochure.

Do this even if the dealer friend already looks. BMW NA’s list is the one that mails recall letters.

## 3. Historic production file — BMW Group Classic Archive

[Archive enquiry](https://www.bmwgroup-classic.com/en/contact/archive-enquiry.html). They hold company/product history, images, sometimes production data. They do not ship web 3D.

> I request any **production / specification record** you can release for VIN `WBAET374X3NJ32467` (E46 325i, Pretoria). I am the owner. I do not need press photos unless that is all you have.

## Do not bother (for this app)

- **ConnectedDrive / 1-888-333-6118** — this car has no CarData/My BMW telematics.
- **aos-api@bmwgroup.com** — Aftersales APIs are for **qualified, paying workshops**, not a private Ledger. Parts API is still “coming soon.”
- Lifestyle / Purebrand licensing — merch and brand extensions, not an E46 GLB.
